Native Apple Silicon testing release for **M1 and later Macs running macOS 15 or newer**.
The arm64 build runs directly on M-series chips; Rosetta is not required.

Download `Heya-0.1.0-alpha.1-macos-arm64.zip` and its `.sha256` file. To verify the download,
run this from the folder containing both files:

```sh
shasum -a 256 -c Heya-0.1.0-alpha.1-macos-arm64.zip.sha256
```

Unzip it, move **Heya.app** into Applications and open it. This beta is **ad hoc
signed and not notarized**. If macOS blocks the first launch, open **System
Settings → Privacy & Security → Open Anyway**, then confirm opening Heya.

Click Connect and scan the QR code using your own phone's WhatsApp → Linked
devices → Link a device. The session and chat archive are encrypted on the Mac;
one master key is stored in Keychain. Allow microphone access when you choose
to record a voice message.

Please test startup and reopening, pairing, received/sent text, emoji, audio
playback with pause/seek/speed, recording and preview, file dialogs, and sleep/wake.
You can discard a recording after preview. Message sending is always explicit.
When reporting a problem, include the Mac model, macOS version, steps and a crash
stack if available; exclude message contents, QR codes and account data.

The build is checked on a macOS 15 Apple Silicon CI runner using synthetic data.
Physical microphone/output routing and live-account behavior on each Mac still
need tester verification. Calls and video playback are not implemented.
macOS versions below 15 and Intel Macs are outside this testing download.
