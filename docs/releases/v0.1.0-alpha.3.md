Native Apple Silicon testing release for **M1 and later Macs running macOS 15 or newer**.
The arm64 build runs directly on M-series chips; Rosetta is not required.

This release adds Heya's Finder/Dock icon at standard and Retina resolutions,
startup diagnostics, and bounded GUI recovery attempts. The icon is now included
and declared in the signed application bundle.

Download `Heya-0.1.0-alpha.3-macos-arm64.dmg` and its `.sha256` file. To verify
the download, run this from the folder containing both files:

```sh
shasum -a 256 -c Heya-0.1.0-alpha.3-macos-arm64.dmg.sha256
```

Close any running Heya instance, open the DMG and drag **Heya.app** onto
**Applications**. Replace the previous application if upgrading, then open Heya
from Applications. Saved account data and Keychain items remain outside the app
bundle. This beta is **ad hoc signed and not notarized**. If macOS blocks the first
launch, open **System Settings → Privacy & Security → Open Anyway**, then confirm.

An existing linked session resumes automatically. On first use, click Connect
and scan the QR code using WhatsApp on your phone → Linked devices → Link a device.
The session and chat archive are encrypted on the Mac; one master key is stored
in Keychain. Allow microphone access when you choose to record a voice message.

If Heya appears in the Dock without a window, use Finder's **Go → Go to Folder**
to open `~/Library/Logs/Heya`. The newest startup logs record the app/build and OS
versions, CPU/model, GUI initialization stages, window geometry and the first
redraw's request/return. Logs exclude message content, credentials, QR payloads
and panic payloads. Up to five logs of at most 64 KiB each are retained; no
monitoring thread is added.

Early backend/component/window-show errors permit one fresh-process attempt
with Skia's CPU renderer, before account services start. This supplements the
existing automatic Metal-to-CPU surface fallback. A native call that hangs
cannot be interrupted by these event-loop checks; the last checkpoint remains
on disk. Close or force-quit the stuck process before trying GUI-only CPU mode:

```sh
/Applications/Heya.app/Contents/MacOS/heya --software-rendering --demo
```

`--demo` uses synthetic chats without opening an account. Omit it for a normal
saved-session launch with CPU rendering. An explicit renderer selection prevents
another automatic retry.

Release checks include native Apple Silicon lint/tests, the shipped icon's ten
representations decoded by Apple's iconutil, synthetic audio helpers, and a
bounded packaged-GUI startup check with both the default and CPU renderers.
These checks establish return from the native redraw call, not physical M4 Air
GPU/compositor behavior. Please report the Mac model, macOS version, reproduction
steps, newest startup logs and any macOS crash report. Exclude account content.

Please also test reopening, pairing, received/sent text, emoji, audio playback,
recording/review, file dialogs and sleep/wake. Sending remains explicit. Physical
microphone/output routing and live-account behavior still need tester verification.
Calls and video playback are not implemented. macOS versions below 15 and Intel
Macs are outside this testing download.
